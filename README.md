# Srinivasa Dumpa — Security Portfolio

GitHub Pages-ready source for the portfolio website.

## Run locally

```bash
npm install
npm run dev
```

## Publish with GitHub Pages

1. Create a GitHub repository and upload or push these files to its `main` branch.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **GitHub Actions** as the source.
4. Open the **Actions** tab and allow the included deployment workflow to finish.
5. GitHub will show the live Pages URL in the completed workflow and Pages settings.

Any later push to `main` automatically rebuilds and republishes the site.
